# 🎓 Kota Student Guide

> **Your digital companion for student life in Kota.**

Kota Student Guide is a modern web application designed to help students explore and discover essential places and services across **Kota, Rajasthan**. From finding suitable accommodation and coaching institutes to discovering food spots, cafés, and other student-friendly locations, the platform brings useful information together in one convenient place.

## ✨ Why Kota Student Guide?

Moving to a new city for education can be overwhelming. Students often need to search across multiple platforms to find accommodation, coaching centres, food, transportation, and everyday essentials.

**Kota Student Guide brings these resources together in one simple and easy-to-use platform.**

## 🚀 Key Features

* 🏠 **Accommodation Discovery**
  Explore PGs, hostels, and student-friendly accommodation options.

* 📚 **Coaching & Education**
  Discover coaching institutes and important educational destinations.

* 🍔 **Food & Cafés**
  Find popular food spots, cafés, and places to relax with friends.

* 📍 **Location-Based Exploration**
  Explore useful places around Kota through an intuitive interface.

* 🧭 **Student-Friendly Navigation**
  Quickly discover places that matter most to students.

* 📱 **Responsive Design**
  Designed to work smoothly across desktops, tablets, and mobile devices.

The goal of **Kota Student Guide** is to create a centralized digital guide for students arriving in Kota, helping them spend less time searching and more time focusing on their education and everyday life.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/kota-student-guide.git
```

### 2. Navigate to the project

```bash
cd kota-student-guide
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
